# MASTER ROADMAP (PHASES 0 – 8)

## รายละเอียดรายเฟส (Detailed Phase Specifications)

### PHASE 0 — Planning and Architecture (ปัจจุบัน)
- **งานหลัก**: วิเคราะห์ความต้องการระบบ, จัดทำเอกสาร SRS, RTM, ERD, Data Dictionary, Financial Invariants, ADR, Threat Model, Test Strategy และ Master Roadmap
- **เงื่อนไขหยุด**: หยุดรอคำสั่งอนุมัติจากผู้ใช้ (เช่น `START PHASE 1`) ก่อนเริ่มเขียนโค้ด

### PHASE 1 — Foundation and Authentication
- **งานหลัก**:
  1. สร้าง Bun Workspace (`apps/desktop`, `apps/server`, `packages/contracts`, `packages/shared`, `packages/config`)
  2. กำหนด Prisma Schema เบื้องต้น (`Store`, `User`, `Role`, `Permission`, `Device`, `Session`, `AuditLog`)
  3. พัฒนา API ยืนยันตัวตนด้วย Argon2id (Login, Refresh, PIN Verify, Screen Lock)
  4. สร้างโครงสร้างหน้าจอ Desktop ด้วย Tauri 2 + React + Vite + Tailwind CSS + shadcn/ui (ธีม Light Mode สีน้ำเงินเข้ม)
  5. พัฒนาหน้า Setup Wizard (ทดสอบต่อเซิร์ฟเวอร์, ลงทะเบียนร้าน, Bootstrap Admin คนแรก, ลงทะเบียนเครื่อง POS)
- **การตรวจสอบ**: ผ่านการทดสอบ Auth, Password Hashing, Session Expire และ Desktop เชื่อมต่อ API ได้จริง

### PHASE 2 — Products and Inventory
- **งานหลัก**:
  1. เพิ่ม Schema สินค้า, หมวดหมู่, บาร์โค้ด, หน่วยนับ, ผู้จัดจำหน่าย, ล็อตสินค้า, การเคลื่อนไหวสต็อก
  2. พัฒนาระบบรับสินค้าเข้าคลัง (Goods Receipt) บันทึกเลขล็อต, วันหมดอายุ และต้นทุนต่อหน่วย
  3. พัฒนาเครื่องมือตัดล็อตสินค้าอัตโนมัติแบบ FEFO (สินค้ามีวันหมดอายุ) และ FIFO (สินค้าทั่วไป)
  4. พัฒนาระบบนำเข้าสินค้าผ่านไฟล์ Excel / CSV พร้อมตัวอย่างและการตรวจสอบความถูกต้อง
- **การตรวจสอบ**: ผ่านการทดสอบสต็อกไม่ติดลบ, การแปลงหน่วยนับแม่นยำ และการจัดสรรล็อตถูกต้อง

### PHASE 3 — Core POS and Payments
- **งานหลัก**:
  1. พัฒนาหน้าจอขายที่รองรับคีย์บอร์ดเป็นหลัก (F2–F10, Ctrl+N, Esc) และรองรับเครื่องยิงบาร์โค้ด
  2. ระบบจัดการหลายบิลพร้อมกัน และระบบพักบิล (Held Bills)
  3. ระบบตัดสต็อกแบบ Atomic ภายใน Database Transaction ด้วย Row-level Lock (`SELECT ... FOR UPDATE`)
  4. ระบบชำระเงิน: เงินสด (คำนวณเงินทอน), บันทึกสลิปโอน/QR PromptPay, แยกชำระ (Split Payment)
  5. ระบบพิมพ์ใบเสร็จความร้อน ESC/POS (58มม. และ 80มม.) และสั่งเปิดลิ้นชักเก็บเงิน
  6. ระบบคืนสินค้าและคืนสต็อกตามล็อตเดิม พร้อมระบบขออนุมัติด้วย PIN ผู้จัดการ
- **การตรวจสอบ**: ทดสอบคำสั่งซื้อพร้อมกัน (Concurrency Test), ทดสอบ Idempotency ป้องกันบิลซ้ำ

### PHASE 4 — Membership and Shares
- **งานหลัก**:
  1. ระบบทะเบียนสมาชิก และการค้นหาสมาชิกด้วยบัตรบาร์โค้ด/เบอร์โทรศัพท์ (F3)
  2. ระบบราคาสมาชิกในหน้าจอ POS และการบันทึกยอดซื้อสะสมลง `member_purchase_ledgers` อัตโนมัติ
  3. ระบบจัดการบัญชีหุ้นสมาชิก (บันทึกซื้อหุ้นเพิ่ม, ถอนหุ้น, โอนหุ้น, ประวัติการเคลื่อนไหวหุ้น)
- **การตรวจสอบ**: สมาชิกลดราคาถูกต้อง, บัญชียอดซื้อสะสมตรงกับบิลขาย, ประวัติหุ้นตรวจสอบย้อนหลังได้ 100%

### PHASE 5 — Dividends and Purchase Rebates
- **งานหลัก**:
  1. ระบบงวดบัญชี (Accounting Periods)
  2. ระบบแม่แบบสูตรปันผล (แยกเงินปันผลตามหุ้น และเงินเฉลี่ยคืนตามยอดซื้อ)
  3. เอนจินคำนวณผลลัพธ์และระบบจำลองผล (Preview) แสดงยอดรายคนและตรวจจับสิ่งผิดปกติ
  4. ระบบอนุมัติและล็อกงวดบัญชีอย่างถาวร (`APPROVED_LOCKED`)
  5. ระบบบันทึกการจ่ายเงินปันผล (เงินสด/โอนเงิน) และติดตามยอดคงค้าง
- **การตรวจสอบ**: ทดสอบความแม่นยำของตัวเลขทศนิยม ปราศจากส่วนต่างแม้แต่สตางค์เดียว, ผลลัพธ์ในงวดที่ล็อกไม่สามารถแก้ไขได้

### PHASE 6 — Dashboard, Reports, and Shifts
- **งานหลัก**:
  1. ระบบเปิด-ปิดกะแคชเชียร์ บันทึกเงินทอนเริ่มต้น และกระทบยอดเงินสดขาด/เกิน
  2. แดชบอร์ดสรุปยอดขายตามสิทธิ์ผู้ใช้งาน
  3. รายงานยอดขาย, กำไรขั้นต้นตามล็อตสินค้าจริง (COGS), สต็อกคงเหลือ, ประวัติปันผล
  4. ระบบส่งออกรายงานเป็น Excel (.xlsx) และ PDF ภาษาไทย
- **การตรวจสอบ**: เงินในลิ้นชักตรงกับรายงานกะ, กำไรคำนวณจากล็อตสินค้าจริง, ส่งออกไฟล์สมบูรณ์

### PHASE 7 — Settings, Backup, and Deployment
- **งานหลัก**:
  1. หน้าจอตั้งค่าร้านค้า, ปรับแต่งข้อความใบเสร็จ, ทดสอบฮาร์ดแวร์
  2. โครงสร้างการตั้งค่าภาษีมูลค่าเพิ่ม (VAT Configuration Foundation)
  3. สคริปต์สำรองฐานข้อมูลอัตโนมัติ (pg_dump + GPG encryption) และสคริปต์กู้คืน (restore.sh)
  4. Docker Compose สำหรับ Production (Caddy + Bun API + PostgreSQL)
  5. จัดทำคู่มือการติดตั้ง (`INSTALLATION_TH.md`) และคู่มือการใช้งาน (`USER_MANUAL_TH.md`)
- **การตรวจสอบ**: ทดสอบ Restore ฐานข้อมูลสำเร็จ 100%, ใช้งานผ่าน HTTPS ได้อย่างปลอดภัย

### PHASE 8 — Security, Performance, and User Acceptance
- **งานหลัก**:
  1. ทดสอบโหลดการขายพร้อมกัน 5 เครื่องจำลอง
  2. ทดสอบจำลองธุรกรรม 10,000 บิลเพื่อกระทบยอดปันผลและการเงิน
  3. ตรวจสอบความปลอดภัยตามมาตรฐาน OWASP และสิทธิ์ RBAC
  4. ตรวจสอบความเร็ว P95 ค้นหาสินค้า < 300ms, ยืนยันบิล < 2s
  5. ส่งมอบระบบและเช็กลิสต์ตรวจรับระบบ (UAT Sign-off)
