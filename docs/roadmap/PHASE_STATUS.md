## กฎการเปลี่ยนสถานะ (Status Transition Rules)
1. สถานะที่เป็นไปได้:
   - ⚪ `NOT STARTED`: ยังไม่ได้รับอนุมัติให้เริ่มต้น
   - 🟡 `IN PROGRESS`: ได้รับอนุมัติและกำลังดำเนินการพัฒนา
   - 🔵 `IN REVIEW / VERIFICATION`: พัฒนาเสร็จสิ้นแล้ว อยู่ระหว่างการทดสอบและตรวจรับ
   - 🟢 `COMPLETED`: ผ่านเกณฑ์ Acceptance Criteria และผู้ใช้รับรองแล้ว
   - 🔴 `BLOCKED`: มีข้อติดขัดทางเทคนิคหรือรอการตัดสินใจเชิงธุรกิจ
2. **ห้ามเริ่มเฟสถัดไปโดยเด็ดขาด** หากเฟสก่อนหน้ายังไม่ขึ้นสถานะ 🟢 `COMPLETED` และยังไม่ได้รับคำสั่งอนุมัติจากผู้ใช้โดยตรง (เช่น `START PHASE X`)
