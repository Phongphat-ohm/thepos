# คู่มือใช้งาน ThePOS

## เริ่มงานขาย

เข้าสู่ระบบแล้วเปิดกะพร้อมบันทึกเงินทอนเริ่มต้น เปิดหน้าขายและใช้ F2 สแกนสินค้า ใช้ F3 ค้นหาสมาชิก และ F9 ชำระเงิน ตรวจยอดและชนิดการชำระก่อนยืนยัน คืนสินค้าจากประวัติการขายโดยเลือกใบเสร็จเดิมและให้ผู้จัดการอนุมัติ

## คลังสินค้า

สร้างสินค้าและผู้จัดจำหน่ายจากทะเบียนก่อนรับเข้า เลือกผู้จัดจำหน่ายและเพิ่มล็อตโดยระบุจำนวน ต้นทุน และวันหมดอายุเมื่อสินค้ากำหนดให้ติดตาม ตรวจรายการในใบรับเข้าก่อนบันทึก ใช้หน้าสต็อกคงเหลือดูยอดรายล็อต และใช้หน้าความเคลื่อนไหวสต็อกตรวจที่มาของการเปลี่ยนแปลง ส่งผลนับจากหน้าบันทึกตรวจนับ แล้วให้ผู้จัดการตรวจในหน้าใบตรวจนับสต็อก

## รายงานและปิดกะ

เลือกประเภทรายงานและช่วงวันที่ แล้วกดแสดงรายงานก่อนส่งออก Excel หรือ PDF เมื่อจบกะให้ตรวจรายการเงินเข้าออก นับเงินสดจริง และกดยืนยันปิดกะ ระบบขอ PIN ผู้จัดการเมื่อผลต่างเกินวงเงินที่ตั้งไว้

## ข้อมูลร้านและอุปกรณ์

ผู้ดูแลเปิดเมนู **การดูแลระบบ → ตั้งค่าร้านและอุปกรณ์**

- **แก้ไขข้อมูลร้าน** บันทึกชื่อ ที่อยู่ เลขผู้เสียภาษี หัวและท้ายใบเสร็จ และโลโก้ JPG/PNG ดูตัวอย่างใบเสร็จก่อนใช้งานจริง ค่า VAT ในหน้านี้เก็บไว้สำหรับเตรียมใช้งาน
- **ตั้งค่าเครื่องพิมพ์** เลือกคิว Windows และกระดาษ 58 หรือ 80 มม. เปิด ESC/POS เมื่อเครื่องพิมพ์รองรับ เลือกตัดกระดาษหรือเปิดลิ้นชักตามอุปกรณ์ จากนั้นกดพิมพ์ทดสอบและตรวจผลที่เครื่อง
- **ทดสอบลิ้นชัก** ตรวจว่าพื้นที่รอบลิ้นชักว่างก่อนยืนยัน ระบบส่งใบเสร็จทดสอบพร้อมคำสั่งเปิดลิ้นชัก
- **ทดสอบเครื่องสแกน** ตั้งข้อความนำหน้าถ้ามี เลือก Enter หรือ Tab ให้ตรงกับอุปกรณ์ แล้วสแกนลงช่องทดสอบ ตรวจว่ารหัสที่แสดงตรงกับฉลาก

ฝ่ายดูแลเซิร์ฟเวอร์ตรวจสถานะสำรองและฝึกกู้คืนตาม [คู่มือติดตั้ง](INSTALLATION_TH.md)
