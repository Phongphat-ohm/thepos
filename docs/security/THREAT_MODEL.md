# THREAT MODEL & SECURITY ARCHITECTURE
## การวิเคราะห์ภัยคุกคามและการควบคุมความปลอดภัย

เอกสารนี้ระบุการประเมินภัยคุกคามตามกรอบการทำงาน STRIDE และมาตรการบรรเทาความเสี่ยงด้านความปลอดภัยสำหรับระบบ POS สหกรณ์ชุมชน

---

## 1. การวิเคราะห์ภัยคุกคามตามแบบจำลอง STRIDE (Threat Matrix)

| หมวดหมู่ภัยคุกคาม | รูปแบบการโจมตีที่เป็นไปได้ | มาตรการควบคุมและป้องกัน (Mitigation) |
|---|---|---|
| **Spoofing (การปลอมแปลงตัวตน)** | ผู้ไม่หวังดีแอบอ้างเป็นแคชเชียร์หรือผู้จัดการเพื่อเข้าใช้งานระบบ | - ใช้รหัสผ่านและ PIN ที่แฮชด้วย Argon2id<br>- ตรวจสอบ Device Token ของเครื่อง POS ที่ลงทะเบียนไว้<br>- ล็อกหน้าจออัตโนมัติเมื่อไม่มีการเคลื่อนไหวเกิน 15 นาที |
| **Tampering (การแก้ไขข้อมูลโดยมิชอบ)** | การดัดแปลงยอดขาย, สต็อก หรือยอดเงินปันผลในฐานข้อมูล | - ไม่อนุญาตให้เครื่องลูกข่ายต่อตรงเข้าฐานข้อมูล (ผ่าน Hono API เท่านั้น)<br>- บันทึกประวัติการเปลี่ยนแปลงทุกรายการใน `audit_logs`<br>- ล็อกงวดบัญชีปันผลถาวร (`APPROVED_LOCKED`) |
| **Repudiation (การปฏิเสธความรับผิดชอบ)** | แคชเชียร์ปฏิเสธการให้ส่วนลดหรือเงินสดขาดในลิ้นชัก | - บันทึก User ID, Terminal ID, Timestamp และ Reason ในการทำรายการสำคัญ<br>- ระบบปิดกะต้องบันทึกยอดเงินจริงและการลงนามยืนยัน |
| **Information Disclosure (ข้อมูลรั่วไหล)** | ข้อมูลสมาชิกหรือยอดเงินปันผลถูกขโมยหรือเปิดเผยสู่สาธารณะ | - ส่งข้อมูลผ่าน HTTPS / TLS 1.3 เท่านั้น<br>- เข้ารหัสเลขบัตรประชาชนด้วย AES-256-GCM<br>- ทำ Data Masking เบอร์โทรและเลขบัตรบนหน้าจอ POS ตามหลัก PDPA |
| **Denial of Service (DoS / ขัดขวางการทำงาน)** | ยิงคำขอขายซ้ำๆ หรือ Brute-force รหัสผ่านจนระบบล่ม | - กำหนด Rate Limiting ที่ฝั่ง Reverse Proxy และ Hono Middleware<br>- ล็อกบัญชีผู้ใช้ชั่วคราวเมื่อใส่รหัสผิดเกิน 5 ครั้ง |
| **Elevation of Privilege (การยกระดับสิทธิ์)** | แคชเชียร์พยายามเข้าถึงหน้าอนุมัติเงินปันผลหรือรายงานกำไร | - ตรวจสอบสิทธิ์แบบ RBAC อย่างเข้มงวดที่ฝั่ง Backend API ทุก Endpoint<br>- การซ่อนปุ่มบนหน้าจอมีไว้เพื่อ UX เท่านั้น ไม่ถือเป็นการป้องกัน |

## 2. การควบคุมความปลอดภัยสำหรับเดสก์ท็อปไคลเอนต์ (Tauri 2 Hardening)

1. **Content Security Policy (CSP)**: บังคับใช้ CSP อย่างเข้มงวด ไม่อนุญาตให้โหลดสคริปต์ภายนอกหรือรัน `eval()`
2. **Scoping Tauri IPC**: จำกัดสิทธิ์การเรียกคำสั่งของ Rust เฉพาะโมดูลฮาร์ดแวร์เครื่องพิมพ์ใบเสร็จและลิ้นชัก ไม่อนุญาตให้รันคำสั่ง Shell หรือเข้าถึงระบบไฟล์ทั่วไป
3. **Secure Token Storage**: จัดเก็บ Session Token ใน Windows Credential Manager ผ่านเนทีฟปลั๊กอินของ Tauri แทนการเก็บใน LocalStorage แบบธรรมดา
