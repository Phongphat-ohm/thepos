# SECURITY CHECKLIST
## รายการตรวจสอบความปลอดภัยของระบบ

---

## 1. การตรวจสอบความปลอดภัยการยืนยันตัวตนและการจัดการเซสชัน
- [ ] รหัสผ่านผู้ใช้งานถูกแฮชด้วย Argon2id พร้อมเกลือ (Salt) และตั้งค่า Memory Cost / Iterations ที่ได้มาตรฐาน
- [ ] รหัส PIN ของผู้จัดการถูกแฮชด้วย Argon2id และไม่ปรากฏใน Audit Log ในรูปแบบ Plaintext
- [ ] เซสชันมีอายุจำกัด และถูกเพิกถอน (Revoked) ได้เมื่อผู้ใช้ทำการ Logout หรือเปลี่ยนรหัสผ่าน
- [ ] หน้าจอ POS ล็อกตัวเองอัตโนมัติ (Auto-lock) หลังไม่มีการสัมผัสหรือกดคีย์บอร์ดเกิน 15 นาที
- [ ] มีระบบป้องกันการเดารหัสผ่าน (Login Rate Limiting) สูงสุด 5 ครั้งก่อนระงับบัญชีชั่วคราว

## 2. การตรวจสอบความปลอดภัยของ API และการเข้าถึงข้อมูล
- [ ] ทุก API Endpoint ที่ไม่ใช่หน้าล็อกอิน ต้องผ่าน Middleware ตรวจสอบ Bearer Token
- [ ] มีการตรวจสอบสิทธิ์ตามบทบาท (RBAC) ที่ฝั่ง Server ทุกครั้ง ไม่พึ่งพาการซ่อนปุ่มฝั่ง UI
- [ ] ทุกคำขอ (Request) ต้องผ่านการตรวจสอบ Type & Format ด้วย Zod Schemas
- [ ] คำขอยืนยันการชำระเงินรองรับ `Idempotency-Key` เพื่อป้องกันการบันทึกซ้ำซ้อน
- [ ] ป้องกัน SQL Injection โดยใช้งาน Prisma ORM Parameterized Queries ทั้งหมด

## 3. การคุ้มครองข้อมูลส่วนบุคคล (PDPA Compliance)
- [ ] เลขบัตรประจำตัวประชาชนของสมาชิกถูกเข้ารหัส (AES-256-GCM) ก่อนบันทึกลงฐานข้อมูล
- [ ] หน้าจอแสดงข้อมูลสมาชิกมีการปกปิดข้อมูลบางส่วน (Data Masking เช่น `081-XXX-4567`)
- [ ] บันทึกการเข้าดูหรือแก้ไขข้อมูลส่วนบุคคลลงใน `audit_logs`

## 4. ความปลอดภัยของระบบฐานข้อมูลและการสำรองข้อมูล
- [ ] บัญชีผู้ใช้ฐานข้อมูล (Postgres User) ใช้หลักการสิทธิ์ต่ำสุด (Least Privilege)
- [ ] ฐานข้อมูลไม่เปิดพอร์ตให้สาธารณะเข้าถึงโดยตรงจากภายนอก (เข้าถึงได้เฉพาะในเครือข่าย Docker ภายใน)
- [ ] ไฟล์สำรองข้อมูล (Backup) ถูกเข้ารหัสด้วย GPG ก่อนจัดส่งออกไปจัดเก็บภายนอก
- [ ] ได้รับการทดสอบกระบวนการกู้คืนข้อมูล (Disaster Recovery Drill) อย่างน้อย 1 ครั้ง
