# การใช้งานระบบนับสต๊อกผ่านมือถือในวง Wi-Fi (LAN + Auto HTTPS)

ระบบนับสต๊อกผ่านมือถือของ **ThePOS** จะ **ตรวจจับ IP วง LAN จริง** และ **สร้าง HTTPS อัตโนมัติ** ให้ทันทีที่เปิดเซิร์ฟเวอร์ โดยไม่ต้องติดตั้งโปรแกรมเสริม

## 1. ค่าเริ่มต้นที่พร้อมใช้งานทันที

- `API_HOST=0.0.0.0` (เปิดรับการเชื่อมต่อจากมือถือในวง Wi-Fi เดียวกัน)
- `API_PORT=3000` (HTTP สำหรับเครื่อง POS และระบบเดิม)
- `AUTO_HTTPS=true` / `HTTPS_PORT=3443` (HTTPS อัตโนมัติสำหรับมือถือและกล้องสแกนบาร์โค้ด)
- `SERVE_WEB_DIST=true` (เสิร์ฟหน้าเว็บและหน้านับสต๊อก `/stock-count` จากเซิร์ฟเวอร์เดียวกัน)

เมื่อรันเซิร์ฟเวอร์ (`bun run start`) ระบบจะสร้างใบรับรอง ECDSA P-256 (Self-signed SAN) ตาม IP วง LAN ของเครื่องไว้ใน `.tls/` อัตโนมัติ และแสดงลิงก์จริงในหน้าต่าง Console รวมถึงสร้าง **QR Code** บนหน้าจอ Desktop โดยใช้ IP จริงและ `https://...:3443` ให้อัตโนมัติ (ไม่ชี้ไปที่ `127.0.0.1`)

## 2. การใช้งานบนมือถือครั้งแรก

1. มือถือเชื่อมต่อ **Wi-Fi เดียวกับเครื่อง POS**
2. สแกน **QR Code** จากหน้า **คลังสินค้า → นับสต๊อกผ่านมือถือ** บน Desktop
3. หากเบราว์เซอร์บนมือถือ (Chrome / Safari) แจ้งเตือนใบรับรองความปลอดภัย (เนื่องจากเป็น HTTPS ภายในร้านแบบ Self-signed):
   - **Android Chrome:** กด **ขั้นสูง (Advanced)** → **ไปยัง <IP> (ไม่ปลอดภัย) / Proceed**
   - **iOS Safari:** กด **แสดงรายละเอียด (Show Details)** → **เยี่ยมชมเว็บไซต์นี้ (visit this website)**
4. หลังจากนั้นระบบจะเปิดใช้งาน **กล้องสแกนบาร์โค้ด** ได้ทันที

> **หมายเหตุ:** หากต้องการให้ไม่มีหน้าต่างแจ้งเตือนใบรับรองเลย สามารถใช้ Caddy (`tls internal`) หรือโดเมนภายในร้านแทน โดยกำหนด `TLS_CERT_PATH` และ `TLS_KEY_PATH` หรือตั้ง `AUTO_HTTPS=false` แล้วให้ Caddy ทำ Reverse Proxy มาที่ `127.0.0.1:3000`
