# คู่มือการ Deploy และใช้งานบริการหน้าเว็บกลาง (`apps/web`)

บริการ **`apps/web`** เป็นเว็บแอปพลิเคชันแยกอิสระ (Static SPA) ที่ใช้โค้ด UI ร่วมกับ Desktop App ผ่าน `@thepos/ui` เพื่อให้ร้านค้าแต่ละร้านสามารถเปิดเบราว์เซอร์เข้ามาที่เว็บกลางของเรา แล้วกรอก **ที่อยู่เซิร์ฟเวอร์ (Server URL)** และ **รหัสเชื่อมต่อเซิร์ฟเวอร์** เพื่อจัดการระบบหลังบ้านของร้านตนเองได้โดยตรง

---

## 1. การรันและ Build `apps/web`

```powershell
# โหมดพัฒนา (รันบนพอร์ต 4173)
bun run dev:web

# Build ไฟล์ Static สำหรับ Deploy (ผลลัพธ์อยู่ที่ apps/web/dist)
bun run build:web
```

หรือ Deploy ด้วย Docker (Caddy Static Web Server):

```powershell
docker build -f infra/docker/Dockerfile.web -t thepos-web .
docker run -d -p 8080:80 --name thepos-web thepos-web
```

> **หมายเหตุ:** เมื่อนำไปวางหลัง Reverse Proxy / Cloudflare / Nginx ให้เปิดใช้งานผ่าน **HTTPS** เสมอ เพื่อให้เบราว์เซอร์เชื่อมต่อไปยังเซิร์ฟเวอร์ `https://...` ของร้านค้าแต่ละแห่งได้อย่างปลอดภัย

---

## 2. การตั้งค่าฝั่งเซิร์ฟเวอร์ของร้านค้า (`apps/server`)

เพื่อให้เซิร์ฟเวอร์ของร้านค้าอนุญาตให้เว็บกลางเชื่อมต่อข้ามโดเมน (Cross-Origin) ได้ ร้านค้าต้องตั้งค่าใน `.env` ดังนี้:

1. **กำหนด `CORS_ORIGINS`** ให้ตรงกับโดเมนของเว็บกลาง (คั่นด้วย `,` หากมีหลายโดเมน):
   ```env
   CORS_ORIGINS=https://web.ourdomain.com
   ```
2. **เปิดใช้งาน HTTPS** บนเซิร์ฟเวอร์ของร้านค้า (เช่น ผ่าน Caddy / Cloudflare Tunnel / Reverse Proxy) เนื่องจากเบราว์เซอร์ไม่อนุญาตให้เว็บ `https://` เรียก API ไปยัง `http://` (Mixed Content)
3. นำ **Server URL** และ **รหัสเชื่อมต่อเซิร์ฟเวอร์** (ดูได้จาก `/server-admin` ของร้าน) มากรอกบนหน้าเว็บกลางเพื่อลงทะเบียนอุปกรณ์เว็บ (`isWebDevice = true`) และเข้าสู่ระบบ

---

## 3. ขอบเขตสิทธิ์การใช้งานบนเว็บกลาง

- เบราว์เซอร์ที่เชื่อมต่อผ่าน `apps/web` จะถูกลงทะเบียนเป็น **อุปกรณ์เว็บ (`isWebDevice = true`)**
- **อนุญาต:** ภาพรวมระบบ, รายงาน (14 ประเภท + ส่งออก Excel/PDF), จัดการสินค้า/สต็อก/รับเข้า/ใบตรวจนับ, สมาชิกและหุ้น, ปันผลและเฉลี่ยคืน, ตั้งค่าร้าน/พนักงาน/เครื่อง POS/Audit Log, และปิดกะแทน (สำหรับผู้จัดการที่มีสิทธิ์ `shift:review`)
- **สงวนสิทธิ์เฉพาะเครื่องหน้าร้าน (Desktop):** ไม่อนุญาตให้ทำรายการขายหน้าร้าน (`sales:checkout`) หรือเปิด/คุมลิ้นชักเงินสด (`shift:operate`) จากเว็บ เพื่อความปลอดภัยของเงินสดหน้าร้าน
